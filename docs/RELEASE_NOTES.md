**FlashVita** — play Flash games (`.swf`) on your PS Vita. Built on [Ruffle](https://ruffle.rs). Made by İbrahim Doğan.

### Install

1. Download **`flashvita.vpk`** below and install it with **VitaShell**.
2. Create the folder **`ux0:data/FlashGames/`** and copy your `.swf` files into it (subfolders work).
3. Launch **FlashVita** from the home screen and pick a game.

If a game needs extra files (levels, external `.swf`s, `.xml`), keep them in the same folder as the game.

### Highlights

- Game library with automatic cover art, SWF details and play history
- Touch screen works as the mouse; optional rear-touchpad trackpad
- Per-game button mapping to any keyboard key or mouse click, on an on-screen keyboard
- Analog sticks as arrows, WASD or a mouse cursor
- Pause menu: **SELECT**, or **L + R + START** at any time
- Fit / stretch / zoom scaling, quality presets, FPS counter
- Runs the CPU at 444 MHz and the GPU at 222 MHz

Requires a Vita with HENkaku / Ensō. Saves, settings and `log.txt` live in `ux0:data/flashvita/` — please attach `log.txt` to bug reports.
